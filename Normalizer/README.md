# Normalizer

Purpose: Convert heterogeneous scanner outputs into a concise, LLM-ready payload describing each finding and the exact file span to patch.

Inputs:
- Default: `Detection/output/raw/` (generated by the Detection layer)
- Custom: pass `--raw <dir>` to override

Outputs:
- `output/llm_payload.json` (list of items sent to LLMs)
- Optional: `output/normalized_findings.json` (verbose normalized records) when `--emit-normalized 1`

Usage (Windows PowerShell):
- From repo root:
  - `python .\Normalizer\normalize.py --raw Detection\output\raw --out output --emit-normalized 1`

Flags:
- `--raw` path to raw detector outputs
- `--out` output directory (defaults to `output`)
- `--emit-normalized` set to `1` to write the optional normalized file

Notes:
- The payload is schema-lite and stable; it includes at minimum: file, category, hints, and location context.
- The orchestration layer discovers the payload at `output/llm_payload.json` by default.
